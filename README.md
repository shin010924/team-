# 층간 소음측정 기기

압전소자를 이용한 층간 소음 측정

## 문제

층간 소음으로 인한 분쟁 시 측정한 데이터의 직관적인 수치로 분쟁 해결

## 사용 부품 및 기술

- 라즈베리파이
- 피에조 충격 탭 센서
- RTC 모듈
- MAX4466 마이크 증폭 모듈

## 시스템 구성

입력(센서) → 판단(코드) → 출력(동작) → 표시(화면/웹)

> 블록도 이미지를 여기에 넣으세요. 손그림 사진도 괜찮습니다.

## 실행 방법

1. 부품을 배선표대로 연결합니다.
2. 코드를 보드에 업로드합니다.
3. 전원을 연결하면 화면에 측정값이 표시됩니다.

## 시연

(3인 팀)
하드웨어-신윤철

기획/BM-장현우

## 막혔던 문제와 해결

압전소자의 설치 위치와 고정 상태에 따라 동일한 충격에도 측정값이 다르게 나타나 정확한 감지 기준을 설정하기 어려웠다. 이를 해결하기 위해 센서의 고정 위치와 배선 상태를 점검하고, 동일한 조건에서 반복 측정하여 센서값을 비교하는 방법을 적용하고자 하였다. 또한 MAX4466 마이크 증폭 모듈을 활용한 소음 측정값 비교와 신호 필터링 및 임계값 조정을 통해 오작동을 줄이는 방안을 마련하였다.
